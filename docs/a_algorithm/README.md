# 算法文档索引

本项目涉及三大类算法：**笔迹特征提取**（从 MMSE/MoCA 绘图任务中提取 92 维笔迹特征）、**VR 行为特征提取**（从四宫格/九宫格 VR 接客任务日志中提取 33 维行为特征）、**数据集构建**（量表读取、特征合并、衍生特征计算）。

---

## 算法分类总览

| 类别 | 文件 | 核心方法 |
|------|------|----------|
| 笔迹几何与运动学 | [01_笔迹特征提取算法.md](01_笔迹特征提取算法.md) | 方向角计算、路径长度、速度/加速度、暂停检测、RDP 点简化、线段交叉检测、封闭环检测、拐角/急转弯检测、路径效率、回溯比例 |
| 笔迹空间与结构分析 | [01_笔迹特征提取算法.md](01_笔迹特征提取算法.md#4-空间与结构分析) | 边界框分析、网格占用率、空间熵（2D 直方图 + Shannon 熵）、对称性评分（Bhattacharyya 系数）、平行度/角度一致性评分、圆度/闭合误差、扇区覆盖/径向熵、指针估计 |
| VR 日志解析与事件匹配 | [02_VR行为特征提取算法.md](02_VR行为特征提取算法.md) | 行协议解析（pipe-delimited JSON）、任务类型识别（INIT_EXP COMM.NAME + 文件名匹配）、续存日志合并（时间继承策略）、EP/MAP/STOP 事件配对、BASE_INFO 遥测数据采集 |
| VR 驾驶行为分析 | [02_VR行为特征提取算法.md](02_VR行为特征提取算法.md#2-驾驶行为分析) | 速度统计（mean/std/max）、静止比例（速度阈值）、刹车激活频率、油门均值、方向盘绝对角统计、路径累积距离 |
| 数据集构建 | [03_数据集构建算法.md](03_数据集构建算法.md) | 被试 ID 统一化、CDR 格式解析、缺失值处理、合并特征计算（加权平均）、差异特征计算（grid9-grid4）、宽表拼接 |
